GroupMate AIClassroom guide
Open classroom workspace

Prepare, discuss and see the outcome

Teachers and students use the webpages. The server calls XIPU, saves validated drafts and keeps API keys on the server. Teacher review is required before students see a generated group outcome.

1. Prepare a case

  1. Sign in as teacher. Start a blank activity, use the sample or reopen an existing draft.
  2. Optionally upload a Module spec or handbook in Course context. Check the page range and extracted text, enter the module name and learning focus, then save. This tells AI what the course teaches; it is separate from case evidence.
  3. In Case materials, upload or paste your case. Saved case materials are reusable documents, not classroom sessions. Check the selected filenames and source text.
  4. Open Generate & review. Choose Prepare a case from these materials or Design the discussion. The default design option covers roles, questions, task, goals and assessment. Click Generate draft, then review and accept or reject the proposal.
  5. Review the nine activity settings and student preview. Selected dimensions are the C1–C6 skills to observe in this activity, not a total grade. Teacher debrief notes are teacher-only guidance, not a student answer. Final review creates no extra report.
  6. Save edits, tick the final review checkbox, click Confirm reviewed settings, then Publish activity & open groups. Create groups and share each join code.

2. Discuss and reflect

  1. Students enter a join code and pseudonym, read the notice and join. There is no separate goal or strategy form.
  2. The teacher clicks Start. Students use Message your group and Send message to share ideas and respond to peers. Optionally select an AI role and click Invite one response after contributing.
  3. The conversation itself is the discussion record. A separate shared proposal or individual confirmation is not required.
  4. The teacher clicks End & freeze. Each student completes Reflect before viewing feedback and clicks Submit reflection (or explicitly skips if allowed). This is the final input step.

3. Publish the group outcome

  1. In the teacher room, open AI generation & teacher review, select WF04C Group report and click Generate with XIPU. It can summarise the frozen chat without a separate group submission.
  2. Review the draft against the actual discussion, including unresolved disagreements. Click Approve and publish only when satisfied.
  3. Students who completed the reflection step see a read-only group poster: summary, reasoning, agreement/open issues and knowledge in use. The bars count actual student messages and exclude AI messages; they are not ability scores.
  4. Open Class overview and select the class session. It shows core counts followed by each group's published outcome. Optional assessment/source details remain collapsed.

Optional teacher analysis

Evidence extraction, independent Observer assessments, individual feedback and class reports remain available in teacher review. They are not required for the simple discussion-to-group-outcome demonstration.

Scope

Controls and new explanations are English. Original messages and quotations retain their original language. The static preview is a labelled simulation; the local classroom is the engine-connected application. Network failures are shown explicitly and do not produce a published result.

The default address http://127.0.0.1:8765/ works on the server computer. Other devices need an appropriate classroom deployment.
