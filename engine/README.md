# GroupMate AI · IBSS课堂案例讨论

本机可运行的完整产品框架：教师准备活动 → 共享案例讨论 → 小组成果 → 个人自评 → 独立Observer → 个人、小组及教师班级报告。课堂用途是形成性反馈，不给正式成绩、总分或排名。

## 人工演示版统一说明

完整按钮操作见 [人工使用手册](docs/manual-release.md)，运行后也可从页面右上角打开。现有七个已发布模块组成同一产品的不同阶段；[统一总入口 v1.0.0](https://aiagent.xjtlu.edu.cn/product/llm/personal/personal-Yongqian.Sun23/workflow/dbe8uif7109350g38f30/update) 已上传并发布，13节点按输入自动选择七个内部子工作流。说明分支与一次真实角色分支已跑通；工作室所有运行链接已统一。API自动传输仍待审批。

## 启动与演示

双击本目录 `run-demo.command`，输入教师口令后打开 http://127.0.0.1:8765 。也可在终端运行：

```sh
export GROUPMATE_OWNER_SECRET='自行设置的教师口令'
python3 -m groupmate.server --port 8765
```

Python 3.9以上；PDF文字提取另需已安装的Poppler `pdftotext`，TXT/MD/DOCX不需要额外Python库。保持同一教师口令可继续管理此前活动。数据存于本机忽略目录 `data/classroom.sqlite`，默认只监听本机。学生用独立标签页或浏览器身份输入邀请码；同机演示不等于跨设备课堂验收。

1. 教师载入IOM420样例或新建活动，选择四种来源路径之一；上传合法材料或粘贴文本。
2. 选择实际提取片段，使用WF01整理资料/案例、WF02建议角色或任务。准备输入，打开对应XIPU工作流试运行，再导入实际JSON，教师决定接受或拒绝。
3. 在结构化表单编辑九项教学决定，检查学生公开预览，逐项确认后发布快照并创建小组。已发布版本可复用，草案可继续编辑。
4. 学生阅读用途/退出说明、填写私有目标与策略、讨论并提交共同建议，每位成员确认或保留意见。教师可计时、暂停、提供公开教学支持与运行角色回应。
5. 结束后学生先自评或明确跳过，再查看已发布反馈，保存下一步行动与体验。
6. 教师审核台依次运行证据提取、独立Observer、个人/小组反馈、班级报告；核对、修订、发布。可导出课堂记录、恢复为独立只读副本，或归档/恢复旧小组。

## 已接入的功能

- 四路径：教师自有案例、教材既有案例、基于教材新编、网络候选检索。真实文本片段、PDF选页、来源和模拟设定分别保存；扫描PDF需先OCR，搜索摘要不冒充全文。
- 教师九项决定：目标、案例、来源、角色、问题/交付、评价重点、课堂节奏/事件、反馈与数据说明、发布确认。直接编辑优先，AI建议不自动覆盖。
- 共享课堂：假名身份、原始发言、公共事实/动态事件、小组提交版本、成员确认、冻结记录。角色背景、诉求、权限、可用信息与禁用行为均可编辑。
- SRL：课前目标/策略、讨论行为记录、课后自评、反馈对照、下一步计划与体验；其他学生不可见个人学习记录。独立Observer不读取目标与自评。
- 评价：MD原文六维四档锚点、本人原话核验、未观察/缺机会/数据缺失说明、课程知识观察。个人反馈沿用独立基线，不靠自评改变等级。
- 支持条件：角色及教师帮助记录本组全部可见成员，报告保留条件与范围；“可见”不证明注意或学习效果。
- 管理：活动复用、草案版本、教师建议审核、自动/审核反馈规则、课堂导出、只读恢复、可恢复归档、逐条MD来源检查入口。

## XIPU连接方式与当前限制

WF01、WF02、WF03、WF04A、WF04B、WF04C、WF05均有对应原生工作流。API审批期间，产品使用手动桥接：准备当前输入 → 在平台真实试运行 → 导入结果。页面不会预填伪AI台词。教师仍需审核案例事实、角色边界与反馈语义。

角色执行器API已获用户授权，但平台发布审批仍待处理，尚未完成自动API联调；本机演示不加载密钥。已有API连接器保留，审批通过后再接入自动传输。不要把手动工作流运行表述为已完成API自动调用。

手动结果包含版本/任务绑定，能检查误贴和过期上下文，但不是执行签名。教材全文仅在教师准备环境使用，学生只收公开活动字段。记录保留天数是教师计划，不是已实现的定时清理任务；退出参与不会自动删除已有教学记录。
