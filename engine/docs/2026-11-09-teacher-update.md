# Teacher feedback changes — 9 November 2026

The current Python engine and browser UI are retained. No new workbench is added.

- White, flat Learning Mall-style surfaces and Arial/system fonts across teacher and student pages.
- GroupMate wordmark includes “Powered by XIPU AI”. IBSS logo from https://www.unprme.org/global-forum/ (231205_IBSS_Logo_RGB-01.png) is stored locally.
- Student materials show only the complete public case and discussion questions. Original contributions remain unchanged.
- A saved student message automatically requests one reply from the selected role. Manual reply remains available after a failure or for an extra turn. No automatic retry of uncertain AI calls.
- One Generate all feedback action runs evidence extraction, each member’s full selected-dimension assessment, then the group synthesis. Successfully saved stages are reused. Publication requires teacher review even if an activity has an automatic release setting.
- Teachers edit judgements and explanations and uncheck dimensions to omit them from released individual feedback. The original AI baseline remains intact.
- Dashboard refreshes server data every eight seconds and on focus, without replacing active forms or drawers. Sessions still preserve their published activity snapshot.
- Source preparation explicitly requests a complete scenario and source references; case preview is never visually truncated. PDF selection defaults to ten pages, with a visible range control.

Core checks: preparation/adoption, discussion/role reply, all-member assessment/edit, teacher publication and student outcome; browser layout and polling check. Real XIPU and server deployment must be separately verified and reported.
